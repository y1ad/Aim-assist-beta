# AimProxy APK (companion)

App Android para copiar rápido los datos de tu proxy:

- Host: `fi11.bot-hosting.cloud`
- IP: `65.108.39.249`
- Port: `26283`

El **aim assist no va dentro de la APK**. Va en el **proxy Go** del host (`bedrock_aim_proxy`).

## Compilar APK (GitHub)
1. Crea repo, sube esta carpeta
2. Actions → Build APK → Run
3. Descarga artifact **AimProxy-debug-apk**
4. Instálalo en el teléfono (fuentes desconocidas)

## Uso
1. Proxy Go corriendo en bot-hosting
2. Abre AimProxy → copia address/puerto
3. Minecraft → Add Server → pega datos
